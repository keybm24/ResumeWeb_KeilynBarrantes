# Personal Portfolio - Keilyn Barrantes

Personal portfolio website built with HTML, CSS, and Bootstrap, showcasing my education, skills, projects, and contact information.

**Live site:** https://keybm24.github.io/ResumeWeb_KeilynBarrantes/

## Pages

- **Home** — Introduction and overview
- **About** — Personal background and skills
- **Education** — Academic history, certifications, and language courses
- **Portfolio** — Showcase of personal and academic projects (Java, Python, C#)
- **Contact** — Contact information and message form

## Built With

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- AOS (Animate On Scroll)
- GLightbox
